# Showcase floor textures

Tileable floor albedo maps for the Showcase render tab, listed in `floors.json` with the real-world
size of one tile (`tile_mm`) and a GGX roughness. Generated by
`scripts/showcase/bake_showcase_assets.py`.

All sources are from ambientCG and are CC0 1.0 Universal (public domain dedication,
https://creativecommons.org/publicdomain/zero/1.0/). ambientCG does not credit individual authors
on its asset pages, so the author is given as "ambientCG". Sources were fetched on 2026-10-18.

## Processing

Only the colour (albedo) map of each material is used.

1. `Concrete034` is 2048 x 1024 (110 x 55 cm); two copies are stacked vertically into a square
   (110 x 110 cm). The other sources are already square (2048 x 2048).
2. Resized to 1024 x 1024 with a Lanczos filter in linear light, with wrap-around padding so the
   result still tiles seamlessly.
3. Saved as baseline (non-progressive) JPEG, quality 85, 4:2:0 chroma subsampling, sRGB, no
   embedded metadata or colour profile.

`tile_mm` follows the physical size ambientCG gives for the material (Wood048 and Wood051 80 cm,
Fabric066 40 cm, Concrete034 110 x 55 cm). Marble012 and Tiles138 have no published size; 600 mm
and 1000 mm (tiles of about 85 mm) are estimates. The roughness values are plausible defaults
chosen for the renderer, not taken from the source roughness maps.

Regenerate with `python3 scripts/showcase/bake_showcase_assets.py --cache <dir with the zips>`.

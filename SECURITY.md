# Security Policy

We take security bugs in EdgeSlicer seriously and appreciate responsible disclosure.

## Supported versions

Only the latest release is supported: https://github.com/aceRage/EdgeSlicer/releases

Fixes are published as a new release. Please check that the problem still exists in the latest release before reporting it.

## Reporting a vulnerability

Please do not open a public issue or discussion for a security bug. Email **info@deftcreations.com** with the word "SECURITY" in the subject line and include:

- The EdgeSlicer version and your operating system.
- What the vulnerability is and who could exploit it.
- Steps to reproduce it, and an example of how it could be exploited.
- Your name and affiliation, if you want to be credited.

We will acknowledge your report within a week and keep you informed until a fix is released.

## Third-party components

Report security bugs in third-party libraries to the people who maintain them.

# EdgeSlicer 2.4.9.6

<!-- update-notice -->
**EdgeSlicer 2.4.9.6** adds filaments for the top surface, bottom surface and ironing, keeps painting through cuts and booleans, and fixes sending to the Centauri Carbon 2.
- New: Top surface, Bottom surface and Ironing filaments in Filament for Features
- New: Import a project 3MF with its object settings
- New: painting is kept through Cut, Mesh Boolean and Split
- Changed: U1 tool change lifts, and Type 2 prime tower acceleration
- Fixed: Elegoo Centauri Carbon 2 upload errors, several crashes, long file paths on Windows
<!-- /update-notice -->

The headline of this release is **surface filaments** and **painting that survives cuts**. It follows [2.4.9.5](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.9.5-edge). Please report problems on [GitHub Issues](https://github.com/aceRage/EdgeSlicer/issues).

## Please read

Behaviour changes that can change your G-code or what slices:
- **Top and bottom surfaces follow the walls in new projects** (#1120, #1125). In a new project the visible top and bottom surfaces print with the outer wall's filament, no longer with the solid infill filament. Where the walls and the solid infill use the same filament, which is every system profile and every single-filament print, nothing changes. A project saved by 2.4.9.5 or earlier, or by another slicer, opens with both surfaces set to its solid infill filament, so it prints as before.
- **Snapmaker U1 tool change lifts** (#399, #1109). Printed by object, every tool change now lifts to 2 mm above the tallest part printed so far, capped at the printable height. Printed by layer, the lift is slower (F600). The slicer now reads the relative lift in the U1 tool change G-code correctly, so moves after a tool change keep their Z clearance. Before, they could drop to about 1.9 mm once the print was taller than that.
- **Type 2 prime tower acceleration** (#1113). With acceleration control on, a Type 2 prime tower now prints at the first layer or default acceleration, or at the prime tower acceleration when that is set. Before, it printed at the travel acceleration left by the move onto it. Bambu printers (Type 1 towers) are not affected.
- **Type 2 prime tower without ramming** (#1117). With "No sparse layers", a tool change that does not ram no longer lowers the nozzle to the tower and lifts it again before the change. This removes a needless retraction and two Z moves at each such change.
- **Command line: same-named filaments** (#1111). Filaments with the same preset name and different colours are now counted as different filaments, so the prime tower is no longer turned off for them.

## New

- **Top surface and Bottom surface filaments** (#1120). Process > Multimaterial > Filament for Features has two new rows after Solid infill. The first entry of each is "Same as walls". The bottom surface filament also covers bottoms printed on support and bridged bottoms. Both can be set per object, part, modifier and height range.
- **Ironing filament** (#1125). A new Ironing row in the same group. "Same as the ironed surface" irons each surface with that surface's own filament. Any other choice irons everything with that filament.
- **Import with object settings** (#350, #1124). Adding a project 3MF to the current project offers a third choice next to "Open as project" and "Import geometry only". It keeps the settings of each object, part, modifier and height range. Scripts, host addresses and similar settings are removed, and filaments the project does not have become filament 1. File > Import asks the same question when the file carries such settings. Preferences > Load Behaviour has a matching entry.
- **Painting kept through a cut** (#1121). Colour, support and seam painting stays on both halves of a plane cut.
- **Painting kept through Mesh Boolean and Split** (#1122). Painting stays on the result of a Mesh Boolean and on the pieces of a split.
- **AMS 3H in the companion apps** (#1127). The H3C's AMS 3H is shown under its name. On every Bambu AMS, the slot that feeds the toolhead is marked "In use".

## Fixes

Printers and sending
- **Elegoo Centauri Carbon 2 upload** (#1128). Sending could fail with "Too Many Requests" (HTTP 429) or error 9004. The upload now uses one connection for the whole file, waits and sends the same part again when the printer says it is busy, and writes the file name the way the printer's own web page does. A 429 and the printer's upload error codes now show a plain message. This could not be tested on a printer before the release. Please report a send that still fails, with the log.

Crashes
- **Crash fixes** (#1114). A crash on quit on macOS, a crash on a click in Measure or Assembly, a crash on Windows when the OpenGL context cannot be activated (an error is shown instead), and a hang in the STEP import dialog.
- **More crash guards** (#1116, #1110). Guards for an empty map lookup, a zero layer height and areas that do not overlap, and two fixes in the Arachne wall generator.
- **17 or more filaments** (#1115). The flush order cache no longer mixes up filament orders with 17 or more filaments.

Files
- **Long paths on Windows** (#554). Files whose full path is longer than 260 characters can be read and written, including inside archives.
- **Command line: AMF in inches** (#1111). An AMF file in inches is no longer treated as a Bambu project, which crashed. It is converted to millimetres.

## Under the hood

- Internal groundwork for later features, and the source encoding check now runs only when a source file changes (#1123).

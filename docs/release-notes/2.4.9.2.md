# EdgeSlicer 2.4.9.2

<!-- update-notice -->
**EdgeSlicer 2.4.9.2** brings full support for the Bambu Lab H3C with the AMS 3H: its nine slots on the Device page, filament sync, sending with slot mapping, and nozzle sync from the rack. It also adds a G-code editor with highlighting and live checks, and startup sounds from MIDI files.
- New: Bambu Lab H3C with AMS 3H (Device page, filament sync, send mapping, load/unload/RFID, nozzle sync from the rack)
- New: G-code template editor with highlighting and live placeholder checks; startup sounds from MIDI files for Bambu printers
- New: SVG modifiers follow curved surfaces; Showcase shows filament modifiers; warning when an object prints nothing on its first layer
- Changed: layers slowed for cooling now really reach the minimum layer time (prints with slowed layers take about 1-3% longer); bridges over sparse infill print as solid infill
- Fixed: H3C refusing files with support on another filament (HMS 0502-4010); H2C/H2D tool changes and timelapse photos; Subdivide mixed colours with a prime tower; many slicing fixes
<!-- /update-notice -->

The headline of this release is the **Bambu Lab H3C with the AMS 3H**, which now works end to end in EdgeSlicer. It follows [2.4.9.1](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.9.1-edge). Please report problems on [GitHub Issues](https://github.com/aceRage/EdgeSlicer/issues).

## Please read

Behaviour changes that can change your G-code or what slices:
- **Layer cooling reaches the minimum layer time** (#973). Lines that only change speed no longer count as moves, so layers that are slowed for cooling now take the full minimum layer time instead of falling 1-10% short. Prints with slowed layers take about 1-3% longer; the fan is set from the real layer time.
- **Bridges over sparse infill** (#969). The first top shell over sparse infill prints as solid infill instead of thick bridge lines, and the bridge direction vote is fixed. Only models with such areas change.
- **Tree supports reach a second overhang** (#984). Split and stepped ledges that were left partly unsupported now get support. Support lengths can change slightly.
- **Wipe tower pressure advance** (#1002). The ramming pressure advance is only sent when pressure advance is set again afterwards. On the Snapmaker U1 and Klipper multi-tool printers without filament pressure advance, the tower no longer overrides the printer's own calibrated value. Where filament pressure advance is on, the filament's value is restored after each ram.
- **H2C/H2D tool changes** (#967, #986). Tool changes use the real wait point, a tower-avoid move and the incoming nozzle's retraction, as Bambu Studio does, and the timelapse photo is taken before the tower travel.
- **Mixed colour sub-layers with a Bambu prime tower** (#937). Subdivide next to a plain colour no longer stops slicing with an "unexpected toolchange" error, and Ratio uses one tool change fewer per layer.
- **Z contouring** (#974). Wipes no longer dig into the line, scarf seams are laid once, and ironing keeps its speed.
- **Many slicing fixes from a line-by-line review** (#945-#983): fuzzy skin, extra perimeters, elephant foot compensation, first layer ironing, arc fitting, polyholes, second internal bridge, precise Z height, vase mode bottom thickness, scarf seams, avoid crossing walls, wipe before external loop, counterbore bridging, walls over overhangs, seam placement, solid fill links, narrow solid infill. Each fixes a wrong result, so affected prints change.

## New

- **Bambu Lab H3C with the AMS 3H** (#987, #990, #997, #1027, #1030, #1031). The Device page reads the AMS 3H's nine slots and per-zone humidity, filaments sync from it with their slot names, sending maps filaments to its slots and the rack nozzles (as Bambu Studio numbers them), and load, unload, edit and RFID work. Sync nozzle sizes reads the nine rack nozzles. The Send dialog's slot picker shows all nine slots.
- **G-code template editor** (#1024). The Edit Custom G-code dialog highlights commands, parameters, comments and placeholders, and checks while you type for unknown names, unbalanced braces and if/endif blocks. Problems are underlined and listed in a status line; saving is never blocked.
- **Startup sounds** (#1029). For Bambu printers whose start G-code plays a tune, a Startup sound button turns a MIDI file into a start tune, with a preview of its length.
- **SVG modifiers follow curved surfaces** (#1018). An SVG on an object uses the surface by default, and changing an SVG part into a modifier keeps it on the surface. The Showcase view colours the areas of modifiers and height ranges that set a filament.
- **First layer warning** (#1013). An object that sits on the bed but prints nothing on its first layer (and so gets no brim) is named in a warning, with the contact width it needs and the settings that fix it.

## Fixes

- **H3C refusing files with support on another filament** (HMS 0502-4010, #1031).
- **Project switch keeps the main tab** (#980): switching projects from the Device or Preview tab no longer lands on Showcase.
- **Print host sends** (#982): sends that hung, reported the wrong outcome or retried the wrong address; the Snapmaker U1 waits long enough for the printer's answer.
- **Printer credentials** stay out of the log, and the saved printers file is private (#981, #1010).
- **Project export and split** (#975, #976): object names no longer create folders in the 3MF, and a split part no longer turns on every save.
- **Duplicate Current Plate** copies the right objects, and plate edits can be undone (#978).
- **Deleting and merging filaments** keeps flushing volumes and layer filament changes right (#983).
- **Command line filament presets** use the high-flow values when a high-flow filament is chosen (#971).
- **Settings pages** (#949, #953, #954, #966, #970): printer and bed type selection, the setup wizard's default filament, labels in the 3D view, and settings shown without sparse infill.

## Under the hood

- macOS builds pin the unversioned SDK and stop early if it is missing (#957).
- The flatpak, Windows and macOS builds include the wxWidgets text editor component used by the new G-code editor (#1024).

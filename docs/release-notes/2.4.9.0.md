# EdgeSlicer 2.4.9.0 (pre-release)

<!-- update-notice -->
**EdgeSlicer 2.4.9.0 is a PRE-RELEASE for testing.** Install it only if you want to try the new features; stable users can stay on 2.4.8.0.
- Bambu Lab H3C profiles, mixed nozzle sizes on one plate, and H2C/H3C rack fixes
- Filament manager and Process manager tables, type-to-filter in filament lists
- Stringing calibration, Layerling tab, open ZIP files directly, minimum layer time pause
- Bambu LAN printers: edit the access code from the pencil; remove or rename stale printers
- Fixes: a crash while generating supports on the H3C, and many Orca upstream fixes
<!-- /update-notice -->

This is a **pre-release build for testing**, not a stable release. It is built from everything merged since [2.4.8.0](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.8.0-edge) and includes everything in it. Please report problems on [GitHub Issues](https://github.com/aceRage/EdgeSlicer/issues).

## Please read

**The H3C mixed-diameter 3MF keys are untested on hardware (#917).** The 3MF now carries the keys Bambu Studio 2.9.1 writes for a job that mixes nozzle diameters, so a mixed-diameter H3C job can be read by the printer. This was checked against Bambu Studio's own output, not on a real H3C. Feedback from H3C owners is very welcome.

Behaviour changes:
- **Paint depth defaults to Unlimited again** (#858). On CAD models where a part's filament paint stopped at the walls, paint now goes all the way through. You can still choose Limited by walls.
- **The print time estimate counts every G4 wait** (#852). Estimates for G-code that pauses with G4 are now longer and more accurate.
- **Preview colour scale follows the visible line types** (#862), and the hidden set is kept when you switch views.

## New

### Bambu Lab H3C and mixed nozzles

- **H3C profiles** (#854, #884). Bambu Studio 2.9.1 profiles for the H3C (one extruder, nine-slot nozzle rack), TPU285 nozzle type, and the 2.9.1 keys for circle compensation, support ironing and the prime tower.
- **Nozzle rack in the interface** (#855, #892, #910, #911, #914). Nozzle tiles per slot, an Extruder Settings dialog, per-nozzle process chips and sections for each rack size, the rack badge on filaments for the H3C, and the H2C/H3C remember their nozzles across restarts.
- **Sync from printer fills all nine rack slots** (#916), and a rack from another printer no longer bleeds in.
- **Mixed nozzle diameters on one plate** (#850, #857, #887, #902, #907, #912, #903). Layers are planned per nozzle size so a 0.4 and a 0.8 nozzle can print on the same plate; supports follow the merged layers, and the Layer height legend shows the right range. This is a port of Bambu Studio 2.9.1's adaptive layer merge.
- **Per-nozzle process fixes** (#869, #871). Chip scope per slot, pin changes recompute widths, stale projects are repaired, and the 3MF records the nozzle diameters as the plate prints.
- **H3C time estimate** (#878). The end G-code air-filtration waits are no longer counted (one test went from 14m40s to 8m34s).
- **H2C/H3C rack slot ids** (#883). The 3MF now names the physical rack slot, which fixes the printer asking to "replace hotend in slot 5".
- **Mixed-diameter warning** (#888). EdgeSlicer warns when an H2C plate mixes nozzle diameters on one rack, because the H2C firmware refuses a mid-print swap between different diameters.

### Preset managers

- **Filament manager and Process manager** (#906, #909). One table of every filament or process preset with search, a filter on each column, sorting, Enabled boxes and favourite stars. User presets can be renamed and deleted from the table.
- **Type to filter** (#904). Type in the filament and preset drop-downs to narrow the list.
- **Sidebar section chevrons** (#919). The Printer and Filament title bars show a chevron, outline and tooltip so it is clear they fold.

### Calibration, printing and slicing

- **Stringing calibration** (#823, #826). A combined temperature x retraction grid, with a dialog, a menu entry and F11/F12.
- **Ironing flow calibration** (#819, Orca #17026).
- **Minimum layer time pause** (#846). For tiny layers the cooling slowdown cannot stretch, park the head and wait (G4). Find it under Process > Speed > Layer time control.
- **Spiral vase with height range modifiers** (#847, Orca #17143, #17154).
- **Override paint** (#845). A modifier's filament can win over colour painting, with clearer warnings when it does not (#843).
- **Color Pattern** (#800, #809). A 3D band overlay and change count; Repeat now counts whole sequences.
- **Airbrush paint** (#802, #808, #810). A colour field baked to paint, an Airbrush tool in the colour-painting gizmo, gradients, patterns and nozzle-aware grain.
- **ImageMap** (#567, #568, #569, #572, #574). Side walls from the dialog, layer stripes, placing the picture and keeping it through a cut, painted textured OBJ files, and face-colour imports.

### Cut and connectors

- **TAC Joint connectors** (#801, #807, #811, #813, #867, #868). A reference-mesh connector with sockets in each half, a Type drop-down, support for curved and drawn cuts, Plugs and Dowels using the kerf on flat cuts, and attachment to either cut half.

### Open and tools

- **Open ZIP files directly** (#829, #832, #853). Extraction is confined to a work folder, and old extracted folders are cleaned up in the background (Preferences section).
- **Layerling tab** (#830, #835). An optional download, a local server, Send to Plate, Edit in Layerling and a STEP round trip.
- **Command line** (#863, #866, #890). A CLI reference, listing presets, quiet output, a richer result.json, validate, output names and exit codes.

### Showcase

- **Realism** (#821, #828, #834, #825). HDRI lighting and backdrop, ground projection, backplate, depth of field, translucency, finishes and camera effects, and a tidier panel.
- **Blender export** (#841). A Blender package export, Open in Blender and the edgeslicer_render add-on.

### Printers and phone

- **Edit the Bambu LAN access code** (#922). The pencil edits the name and the access code, and a printer that refuses the code now shows a notice instead of redialling silently.
- **Remove and Rename stale printers** (#918). The Printers tab and the phone app can remove a printer at its source and rename it; leftover entries are pruned.
- **Filament for Features on every printer** (#926). The wall, infill and prime tower filament settings now show on any printer whenever the project has more than one filament, including Bambu and single-nozzle printers.
- **Print error dialog** (#870). Real error text for every Bambu model and no dead Stop/Resume buttons.
- **Phone hub** (#785, #789, #824, #836, #842, #859, #861, #865). Filament settings and slot removal, a richer layer preview, plates and objects from the phone, tablet colour painting for objects up to 10M triangles, and the prime tower shown and movable from the app.

### Upstream OrcaSlicer ports

- **Wave 4** (#886, #889, #890, #891, #905). Slicing and G-code correctness, validation, GUI and CLI small fixes, multi-extruder correctness, and new profiles (QIDI X-Smart 5, PrintaLot, 3D-Fuel, Sovol, RF50).
- **Single ports** (#771, #772, #773, #774, #816, #817, #818, #838, #839, #848, #849, #851, #873, #874, #876). Among them: the lightning infill hang, the Mesh Boolean crash on unreferenced vertices, sequential print ordering, and a bound on placeholder digits.

## Fixes

- **Filament tool buttons on the Snapmaker U1 and multi-extruder printer switches** (#928). With more filaments than tools, picking a filament's own tool now sticks. Switching a project to a printer with a different extruder layout (H3C to H2C, H2C to U1) starts from a fresh filament map instead of carrying the old pins over.
- **Crash generating supports on the H3C** (#921). Organic tree supports with merged layers could close EdgeSlicer.
- **3MF export with a non-ASCII image name** (#872). The file no longer vanishes, and export errors are shown.
- **Layers shared between objects with different centre offsets** (#840, Bambu #12861).
- **3MF without project settings** (#839). Falls back to the geometry.
- **Minimum layer height on mixed plates** (#912). A value that leaves one slab height no longer drops the coarse object.
- **Process chip layout** (#911). Sidebar re-layout, taller chips, fixed filament badge size.
- **CLI crashes** (#773, #790). With a filament preset that sets no diameter, or more filament presets than the project has.
- **Flush length** (#876, Orca #17270). A small flush is kept in flush_length_1.
- **Preview legend** (#862).

## Known issues

- The H3C mixed-diameter 3MF keys (#917) and the Creality K-series features from 2.4.8.0 have not been tested on real hardware.

## Under the hood

- Local crash dumps are no longer empty when several slicing threads fault at once (#923).
- CI validates profiles with EdgeSlicer's own validator (#860, #864), plus a printer_variant check.
- Build and test fixes for macOS and clang (#778, #799, #820, #827, #844) and the Linux AppImage packaging (#806).
- Docs: German TAC Joint guide removed (#812).

# EdgeSlicer 2.4.6.0

<!-- update-notice -->
New in 2.4.6.0:
- Send to Bambu Connect, and Bambu printers can be added for status only (AMS colours and nozzles) when they print through Connect
- Snapmaker U1 uses your local network first, with the cloud only as a fallback
- Device page: a Storage tab for Klipper and Snapmaker printers
- Vaults on the Home tab: WebDAV, S3, Azure Blob and Synology storage
- Many OrcaSlicer and Snapmaker fixes ported, plus macOS fixes (Device page freeze, Bambu project import)
<!-- /update-notice -->

Everything in [2.4.5.5](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.5.5-edge) is included.

## New

### Bambu Lab

- **Send to Bambu Connect** (#534). A new entry in the Print button's dropdown and under File > Export sends the sliced plate (or all plates) to your own Bambu Connect app, which prints it with your Bambu account or over the LAN. It appears for Bambu printers only. If Bambu Connect is not installed, a short dialog says so and links to its page.
- **Status-only Bambu printers** (#541). Device > Connect via IP can now add a printer that is bound to a Bambu account for status only. EdgeSlicer reads its AMS trays, colours, nozzles and extruders, so "Sync filaments with AMS" and the automatic nozzle match work for printers you print to through Bambu Connect. Nothing is ever sent to such a printer.
- **Secured mode (Developer Mode off)** (#540). A printer that rejects commands from third-party software no longer gets a stream of automatic requests that it answers with errors. Actions that need Developer Mode explain that in one clear message.
- **LAN print from internal storage** (#533). H2-series printers and the P2S that print from internal storage no longer need a storage card for a LAN send.
- **Device list refresh** (#538). The Bambu device list has a refresh button and refreshes by itself when a printer changes between LAN and cloud mode, so a switched printer no longer disappears until you sign in again.
- **Pressure advance mode** (#532). Dual-nozzle prints are sent with Bambu Studio's default pressure advance mode (shared profile).
- **Cancelled prints read as cancelled** (#469). A Bambu print you cancel by hand is a cancel in notifications, Live Activity and the Printers tab, and stays one after the printer clears its error code.
- **Smaller Bambu fixes from OrcaSlicer** (#518, #519). AMS filament lists come in a more useful order, a missing nozzle report from the printer no longer blocks a send or filament sync, and a few device guards are added.

### Snapmaker U1 and Klipper printers

- **U1 local-first connection** (#528). A U1 bound to your Snapmaker account now talks to the printer over your local network whenever it can be reached, and falls back to the cloud per request when it cannot. It is on by default.
- **Storage tab** (#548). The Device page for Klipper (Moonraker) printers and the U1 gets a Storage tab: browse the printer's G-code files with previews and details, sort them, delete them, or start a print (after checking the printer is free).
- **U1 plates and presets** (#543, #502, #520, #493). Cool Plate is available on the U1, with corrected bed temperatures in the U1 filament presets. Also a tower-travel option, a flush cap, a filament sync colour match, per-plate bed types, Z-speed limits respected in generated travel, and variable layer height fixes.
- **Snapmaker web panel update** (#492). The built-in Snapmaker page is updated to the latest version.

### Home

- **Vaults** (#476, #501). A new Vaults section on the Home tab for your own storage: folders and network shares, WebDAV, Azure Blob and S3-compatible storage, with Synology built in. Download & Open works from a vault like from a vendor.
- **Models browser on macOS** (#464). Home > Models (Printables, MakerWorld, Snapmaker Space) now works on macOS 12 and later.
- **Vendors CSV export** (#498). One row per model, split into numbered files with a maximum number of records per file.

### Working with models

- **Favourite filaments** (#531). A star on every preset row and a "Favorite filaments" group at the top of every filament picker.
- **Lay on face** (#482). Small parts now offer faces, and a "Face under cursor" mode picks any flat face directly (hold Alt for it while in the hull mode).
- **Faster printer switching** (#529, #525). Switching printers no longer re-reads every Bambu Studio preset, recentres plates in a single undo step, and keeps bed textures. Startup and preset switches are also faster.
- **Alt+Shift selection** (#474). Add or remove parts to a selection with Alt+Shift.
- **Prime tower reach** (#479). The prime tower stays where the nozzles that print on it can reach (H2D, H2C, X2D).
- **Wipe tower** (#184, #189, #397). The final purge comes from the tower, not the top of the object; tool-change starts can be staggered; fan control markers cover the wipe tower tool change.
- **Stabilizers and vase mode** (#503, #504). Side stabilizers follow wall and infill settings on small columns, and switch off with the other vase mode settings.
- **Mixed-colour matching** (#486). Automatic mixed-colour match ratios are kept within sensible limits.

### From OrcaSlicer

- **Texture displacement follow-ups** (#535). Checker and distortion views, faster net layout, typed values on every panel slider, an image adjustment panel and UV editor fixes.
- **Preset UX and calibrations** (#549, 6A-6 and 6A-7). Remap filament improvements, detached presets, optional auto slice after changes, and calibration fixes.
- **Input shaping** (#500). Input shaping printer options and calibrations per firmware, and a Cornering calibration.
- **Fan options** (#523). A minimum fan PWM per printer, a first-layer fan speed per filament, and exhaust fan controls.
- **Elephant foot compensation for solid layers** (#522), **placeholders and templates** (#526, with `{first_object_name}` and `regex_replace`), **raft and interface patterns** (#472), **spiral lift** (#471), **bridges, overhangs and fuzzy skin** (#473), **time estimate** (#470), **faster TPMS-FK** (#465).
- **Canvas, camera and selection fixes** (#524), **GL and viewer follow-ups** (#480), **print hosts and network** (#467), **macOS pack** (#468), **profile updates** (#466, #491, #494), **slicing correctness** (#495, #506, #496), **config fields and range checks** (#499).

## Fixes

- macOS: the freeze on the Device page after Send is fixed (#546), the last direct web view scripts go through the safe path (#547), and Bambu project settings load again when a 3MF is imported on a Mac (#564).
- Rare hang in mesh booleans fixed (#453). Crash when the window is closed during G-code export (#544) and when the Device tab is closed during a pending slice update (#536).
- Scale and mirror of rotated, mirrored objects (#459), the Slice button no longer sticks after a lost mouse release (#456), the object list edit keeps its undo state (#455), and plate settings refresh after a thumbnail plate pick (#485).
- The G-code preview reloads after in-place post-processing (#460), and `.gcode` files open with their own settings (#508).
- Qidi start G-code follows the selected plate type (#457). Filament grouping updates when the nozzle flow type changes (#484). Small-area infill flow compensation now actually applies (#496).
- G29 preparation time is counted once (#507), Z shrinkage is counted once and includes the raft (#516), and the G-code preview reserves its exact vertex count (#514).
- Snapmaker fixes: manual tree support leak, penetration validation and first-layer travel acceleration (#497).
- U1 filament presets keep pressure advance off (#477).
- Hub: it stops cleanly at logout, restart and window close (#463), and requests arriving through Tailscale Serve without a tailnet login are refused instead of relying on the link token alone (#530).
- Loading is safer against damaged or crafted 3MF, OBJ and STL files (#517, #490, #510, #513).
- Shutdown and startup races are closed: stale updates after the main window is gone (#461), the backup thread after shutdown (#475) and macOS file opens before the window is ready (#483).

## Under the hood

- Tests and comments use generic printer and device names (#481).
- Test fixes for macOS and Windows linking: locale leak, temporary directory, a Windows-only path check, a duplicate event definition (#542, #550, #563).
- Smaller OrcaSlicer cleanups: `Http` filesystem alias (#509).

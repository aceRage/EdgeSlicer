# EdgeSlicer 2.4.9.5

<!-- update-notice -->
**EdgeSlicer 2.4.9.5** brings Curved tops to any printer, a Fine detail setting for thin features, and about 40 fixes to cutting, mesh tools, presets, G-code and sending.
- New: experimental Curved tops now work on any printer once you enter the head clearance in Printer settings
- New: Fine detail setting and a notice when thin features are skipped or printed wider
- New: Split to Fit panel scrolls, with Apply and Reset always in view
- Changed: copies printed by object with 2+ filaments now print one after another with no prime tower
- Changed: CLI arrange places parts towards the printer's best object position
- Fixed: Cut tool connectors, Draw cut and Mesh Boolean errors, object settings lost on a project switch, preset export and import, Z offset between copies printed by object
<!-- /update-notice -->

The headline of this release is **Curved tops on any printer** and **Fine detail**. It follows [2.4.9.4](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.9.4-edge). Please report problems on [GitHub Issues](https://github.com/aceRage/EdgeSlicer/issues).

## Please read

Behaviour changes that can change your G-code or what slices:
- **Copies printed by object have no prime tower** (#1075). With the print sequence set to "By object", several copies of one object and two or more filaments, the copies now print one after another and there is no prime tower. Before, the plate was printed layer by layer with a tower that the 3D view did not show.
- **CLI arrange moves parts** (#1087). The command line's arrange now places parts towards the printer's best object position, as the application does. A plate arranged on the command line can land at a different X/Y than before. This matters most on printers whose best position is not the middle of the bed, such as the H2D family and the A1 mini. Arrange in the application is unchanged.
- **Curved tops on any printer** (#1108). Curved tops now work on any printer once the head clearance values are set in Printer settings. The head values shipped for several printers (X1, X1E, U1, H2D) are estimates, so the slicer asks for a one-time confirmation before it slices with values that have not been verified. Curved tops remain experimental. Check the first print with care.

## New

- **Curved tops on any printer** (#1108). Under Printer settings > Basic information > Head clearance, enter how far the nozzle tip stands below the lowest other part of the head. Without it the object prints flat and the notice says where to enter it. Once per printer preset and set of head values, a dialog asks you to accept the risk. Changing a value asks again. Printers with measured head data, the X1 Carbon and the Centauri Carbon, are not asked.
- **More curved tops options** (#1088, #1094, #1096, #1103). Supports are now allowed under curved tops. Partial curving curves as much of the top as it safely can and prints the lower areas flat. A notice reports a surface that is too steep. The nozzle gets its own contact tolerance. You can choose the fill pattern: Monotonic, Concentric or Spiral, with gap fill and a smoother patch edge. Developer mode adds overrides for the safety limits, for test prints only.
- **Fine detail** (#1101). Thin features can print thinner without changing the walls. A new Fine detail level (off, balanced, fine text or custom) sets the thinnest line and the smallest feature that is printed. It is off by default, so existing profiles slice as before. The Arachne wall settings have clearer names and tooltips, and sit in three groups: Wall generator, Thin features and Wall count changes. The old names are still found by Search.
- **Thin feature notice** (#1104). After slicing, one notice per object says when thin features were skipped or printed wider than the model. It stays quiet unless the total is 5 mm or more, and it offers a fitting suggestion.
- **Stream tile hint** (#1100). A Stream tile that connects but shows no picture now says why after 10 seconds, worded for the camera type, with a Retry button.
- **Split to Fit panel** (#1107). The panel scrolls when it is taller than the 3D view, Apply and Reset stay in view, and the sections can be collapsed.

## Fixes

Cut and mesh tools
- **Cut halves with open edges** (#1001). A cut close to a vertex or a flat face no longer gives a half with non-manifold edges or a zero-volume half. Copies keep their pose and sides with only modifiers are dropped.
- **Cut tool connectors** (#1006). Triangle connectors are cut where they are drawn, turned connectors are checked turned, the dovetail depth follows the zoom, and Edit cut works on plain and turned cuts.
- **Draw cut** (#1008, #1011). A plug drawn on a coarse face is no longer reported as not separating the part, the extension stops only at a wall it runs into, and editing an open line keeps it open.
- **Flexi joint** (#1012). The ball no longer has a band of empty triangles, the thread lead-in no longer pokes through the groove, and cut failures are no longer silent.
- **Mesh Boolean** (#1005, #1023, #1068, #1069, #1070). An empty intersection says so instead of reporting a failure, a failed first attempt falls back to the second method, hollow parts are exported cut, the Delete boxes reset when the tool opens, the boolean and the deletion of the tool part are one undo step, and copies stay copies.
- **Remesh, Repair and Simplify** (#1066, #1067, #1068). Remesh keeps the right voxel size for inside-out parts, Simplify starts at Medium as its slider says, and an untouched voxel field means automatic for each part.
- **Split** (#1077). The pieces of a text or SVG part become plain parts.
- **Auto orient** (#1022). It orients only the objects on the current plate, each by its own mesh.
- **Painting** (#993). The last triangle of a drag is painted, strokes that change nothing no longer add an undo step, and the support undo names are translated.
- **Object settings** (#988, #989). Switching projects no longer erases the settings of the selected object, a height range without a layer height no longer crashes, range heights are checked, and the reset icon of a height range works on macOS.
- **Text** (#1078). Text falls back on a font that ships with the app.

Presets
- **Preset messages and compatibility** (#995). Singular and plural messages are the right way round, user printers of user printers get a system process, and a new preset keeps its time.
- **Preset bundle export and import** (#996). Filament names are no longer cut short, bundles are no longer broken, a parent later in the archive is found, and a preset that is dropped is now reported.
- **Deleting a user printer** (#1025). It deletes only the presets made for that printer alone, not shared or generic ones.
- **Create Printer** (#1026). The "rewrite it?" question can be answered Yes, and the check for an existing preset uses the name that is made.
- **Config** (#1035). A string list item that holds a semicolon is quoted.
- **Calibration dialogs** (#1071). End and Step accept only numbers.

G-code and slicing
- **Organic tree support** (#1003). The bottom Z distance holds under feet carried down a slope.
- **Heat before the start G-code** (#1076). With several tools and a start G-code that sets no nozzle temperature, every printing tool is now heated, not only the last one.
- **Z offset between copies** (#1093). With copies printed by object, the nozzle no longer drops into the finished copy by the Z offset before it travels on.
- **Tool change written twice** (#1092). A change that the change G-code already makes, with a long prefix such as the manual filament change, is no longer written a second time.
- **Fan speed-up time** (#1081). Arcs now take their time in the fan speed-up shift, and there is no empty line after a kick-start.
- **Preload all filaments** (#1095). A plate printed in one filament is no longer refused when the prime tower is on.
- **Filament matching** (#1039). AMS auto-match compares colours correctly and breaks ties by tray, and PET-CF and PA6-CF filaments are blocked for Bambu printers.

Device and send
- **Send dialog** (#1040). The timelapse version check, the add-printer buttons and duplicate config keys are fixed.
- **Bambu access code and tokens** (#1038). They are kept out of the log.
- **Export and open in Bambu Studio** (#1036). On macOS and Linux a missing Bambu Studio is now reported instead of being counted as launched.

CLI
- **CLI project export** (#1037, #994, #995). A project with no filament ids exports with them empty, an STL export keeps the right extension, and --printer-preset works with a user printer.

Other
- **Recent projects and STL export** (#994). A missing project leaves the recent list, the list stays in order past 99 entries, STL names are made safe, and export failures are reported. OBJ vertex 0 is read correctly.
- **German** (#1016). The sliced-file export entries no longer say STL.

## Under the hood

- Documentation validation errors on main are fixed (#1102).
- A memory fix in the wipe tower code (#1057).

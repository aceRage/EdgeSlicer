# EdgeSlicer 2.4.5.3

<!-- update-notice -->
New in 2.4.5.3:
- Snapmaker account sign-in works again (it looked signed in but cloud printers never appeared)
- Signing out of Snapmaker now really signs you out, so the next sign-in shows the form
- Every file in the Windows installer is now signed
<!-- /update-notice -->

Everything in [2.4.5.2](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.5.2-edge) is included.

## Fixes

- **Snapmaker account sign-in** (#433). Snapmaker changed what its sign-in page hands back, and EdgeSlicer read the sign-in token wrongly. The account showed "Snapmaker: signed in" with no name, the Device page treated you as signed out and showed no cloud printers, and signing in again only flashed the window. EdgeSlicer now reads the token correctly and only shows you as signed in once Snapmaker confirms your account. Versions 2.4.5.0 to 2.4.5.2 were affected.
- **Snapmaker sign-out** (#433). Signing out now also clears Snapmaker's saved sign-in in EdgeSlicer's built-in browser (only Snapmaker's, other sites stay signed in), so the next sign-in starts clean instead of flashing.
- **Clear message when Snapmaker sign-in fails** (#433). If the sign-in doesn't complete you are left cleanly signed out with a message saying so, instead of a window that flashes and a menu that claims you are signed in.

## Behaviour changes

- **Every file in the Windows installer is signed** (#432). The installer's own NSIS helper DLLs and the FlashForge network library are now signed too, so nothing in the installer or the portable zip is unsigned.
- **Installer wording** (#429). The upgrade prompt now just says "A previous version of EdgeSlicer is already installed". Old UltraOne and Snapmaker-Ultra installs are still found and offered for removal.

## Known limitations and not tested

- Checked by hand: Snapmaker sign-in, restart and sign-out on Windows (#433).
- Not tested: Snapmaker sign-in on macOS and Linux (same code), and the Windows installer's signed helper DLLs beyond the signature check.
- SmartScreen may still show "isn't commonly downloaded" on the first downloads while the signature builds reputation.

## Under the hood

- The unused standalone `installer.nsi` was removed (#430); Windows installers are built by CPack.

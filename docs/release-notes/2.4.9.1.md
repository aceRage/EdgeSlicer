# EdgeSlicer 2.4.9.1

<!-- update-notice -->
**EdgeSlicer 2.4.9.1** lets you keep several projects open in one window: a project strip along the top switches between them, each with its own thumbnail. It also includes everything from the 2.4.9.0 pre-release.
- New: project strip (several projects in one window), mixed colour sub-layers, TAC joints can be applied to the mesh when cutting
- Changed: by-object printing with a raft can now refuse objects as too tall; the first-layer time in the G-code header now includes the start sequence; normal supports no longer print a first-layer interface under the model; wall groups print nearest-first
- Changed: new option Retract after outer wall (off by default); firmware retraction now works with wipe
- Fixed: a crash when opening Printer settings > Extruder (2.4.9.0 only); some mixed-height plates that failed with "Prime Tower partially outside the printable area" now slice; tree supports slice faster; invalid bed exclusion areas are rejected
<!-- /update-notice -->

The headline of this release is the **project strip**: several projects open in one window, each a click away. It follows [2.4.9.0](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.9.0-edge), which was a pre-release for testing. **This release also includes everything from the 2.4.9.0 pre-release** (Bambu Lab H3C profiles, mixed nozzle sizes, the Filament and Process managers, stringing calibration, the Layerling tab and more); see the [2.4.9.0 notes](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.9.0-edge) for that list. If you are coming from 2.4.8.0, read both. Please report problems on [GitHub Issues](https://github.com/aceRage/EdgeSlicer/issues).

## Please read

If you installed the 2.4.9.0 pre-release: it closed when you opened Printer settings > Extruder (#943). That is fixed here, so please update.

Behaviour changes that can change your G-code or what slices:
- **By-object printing with a raft can now refuse objects as too tall** (#940). The height check now counts the raft (and any raise or Z shrinkage) above the bed, as the print really stands. A plate that used to slice may now report that an object is too tall for by-object printing. By-object order also keeps rotated copies of an object in their list order.
- **The first-layer time in the G-code header now counts the start sequence plus the first layer** (#940). The estimated first layer time comment in the G-code is longer than before because it includes the start sequence.
- **Normal supports no longer print a first-layer interface under the model's footprint** (#941). Support interface layers are also kept when the support layer gaps are synchronized.
- **Wall groups print nearest-first** (#896). Where one filament has several separate islands on a layer (mixed colours, for example), each group of walls is followed by the nearest unprinted group. Travel moves change and usually get shorter; the walls inside each group are unchanged. Single-colour, single-island prints are unchanged.
- **Firmware retraction now works with wipe** (#900). With "Use firmware retraction" and "Wipe while retracting" both on, the whole retraction happens before the wipe and the wipe is a plain move, which fixes under-extrusion after wiped travels. The old prompt that forced wipe off or 100% is gone. "Retract amount before/after wipe" and "Length" are greyed out under firmware retraction.
- **Invalid bed exclusion areas are rejected** (#938). An exclusion polygon that crosses itself or has no area is refused in the settings field and dropped, with an error, when a 3MF is opened.
- **Prime tower sliver layers are joined** (#880). Some mixed-height plates that failed with "Prime Tower partially outside the printable area" now slice. The tower layers on those plates can change.
- **Tree supports slice faster** (#941), and the G-code is meant to stay the same.
- **Snapmaker U1 by-object clearance** (#877). The U1 uses the CAD rod height (27.05 mm) and rod distance (41.2 mm) for collision checks, so a copy that used to fit may now be reordered or refused.
- **Infill ring joins for Gyroid and TPMS** (#939). Infill of these patterns joins its rings, so infill paths change slightly.

## New

- **Several projects in one window** (#920, #934). A project strip along the top lets you keep more than one project open, switch between them, and see a thumbnail of each.
- **Mixed colour sub-layers** (#925, #927). Bambu-style ratio sub-layers for mixed colours on every printer: a toggle, a dialog to choose the method and see the cost, badges on mixed filaments, warnings and a legend.
- **Apply TAC joints to the mesh when cutting** (#932, community contribution by craidos-beep). An optional checkbox in the Cut tool that builds the sockets and attached joints into the cut halves, ready to export as STL. It is off by default, and the editable connector workflow is still available.
- **Support interface settings** (#933). Support interface layer counts can be any number. The interlock settings ask for the layer count when needed, offer a top Z distance of 0 (and remember a No), and ask instead of greying out when interlock and matching settings conflict.
- **Retract after outer wall** (#894, Orca #16982). A new option, off by default, that retracts after the outer wall even on short travels.
- **Preview and printing details** (#885, #881, #879). After a lift, the nozzle travels at the lifted height and descends at the destination instead of sinking diagonally; the final purge on the prime tower lifts before travelling; wipe inward no longer fights wipe on loops.
- **Painted models keep an explicit sparse infill filament** (#897, Orca #17314).
- **Upstream OrcaSlicer updates** (#935, #936, #939, #941). New and updated profiles (PrintaLot PETG for Bambu printers, Sovol SV08 MAX 0.2 and 1.0 nozzles, Recycling Fabrik and EverLoop filaments, Flashforge Creator 5 and Prusa fixes), a Preview tool-position readout that follows the plate, a 3D navigator that keeps the mouse for the whole drag, and imported files that rotate as one piece.

## Fixes

- **Crash opening Printer settings > Extruder** (#943).
- **Crash with more than 36 plates** (#893).
- **Arranged objects stay clear of a compacted prime tower** (#898).
- **Per-part filament colours are kept after a dovetail cut** (#899).
- **EdgeSlicer no longer closes while a dialog is open** (#901), which could lose work.
- **Opening a G-code file from the command line** waits until the 3D view is ready (#895), and the command line exits cleanly on Windows (#936).
- **Klipper printers** no longer get a surplus M400 after wipe-tower flushes (#875).
- **Objects shared by several copies** only share slices when their height-range modifiers match (#940).
- **OBJ colour import** checks the extruder and keeps a stable colour order (#632).
- **Preset loading** routes print, filament and printer settings IDs to their own collections (#938).
- **Downloads** follow redirects to https only, and the final address is checked (#856).
- **Support interfaces** under synchronized layer gaps are no longer trimmed away (#941).

## Under the hood

- The test suite has a separate slow tier so everyday checks run faster (#930).
- Flatpak builds use the current freedesktop SDK (#931).

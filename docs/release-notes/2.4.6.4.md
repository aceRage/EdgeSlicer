# EdgeSlicer 2.4.6.4 (release candidate)

<!-- update-notice -->
New in 2.4.6.4 (release candidate):
- QIDI Box: empty slots no longer show as PLA
- QIDI Box: what is in the Box is read from the slot sensors, as QIDIStudio does
- QIDI Box: if the Box reports contradictory data, the job is uploaded only and not started
- QIDI Box: a filament mapped to an empty slot is never started
- Elegoo CANVAS and Snapmaker U1 sends from the phone, hub and Stream tab: trays mapped like the desktop send dialog
- Elegoo CANVAS and Snapmaker U1 sends: a mismatched material is refused, and a busy printer is refused before anything is uploaded
- Snapmaker U1: a send right after a print finishes is no longer refused
<!-- /update-notice -->

A release candidate on top of [2.4.6.3](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.6.3-edge), for testing the QIDI Box fixes before a stable release. Everything in 2.4.6.3 is included.

## Fixes

- **QIDI Box empty slots** (#661). An empty slot in a QIDI Box could be shown as PLA, so a job could be mapped to it. EdgeSlicer now reads which slots are loaded from the Box's slot sensors, the way QIDIStudio does, and shows empty slots as empty.
- **QIDI Box data that does not add up** (#661). When the printer reports Box data that contradicts itself, no slot can be trusted: the job is uploaded only and not started, and EdgeSlicer says why.
- **QIDI Box filament mapped to an empty slot** (#661). A job with a filament mapped to a slot the printer reports as empty is never started, even after confirming a material warning.
- **Elegoo CANVAS and Snapmaker U1 sends from the phone, hub and Stream tab** (#660). These sends now follow the same slot rules as the desktop send dialog: trays are mapped the way the desktop maps them, a filament going to a tray of another material is refused, and a printer that is busy printing is refused before anything is uploaded.
- **Snapmaker U1 send right after a print** (#660). A U1 that had just finished a print could be seen as busy and refuse the next send. A finished print no longer counts as busy.

# EdgeSlicer 2.4.8.0

<!-- update-notice -->
New in 2.4.8.0:
- Multicolour filaments: dual and tri-colour, gradient and glow-in-the-dark filaments show in Showcase and Preview (visual only, no G-code change)
- Color Pattern: repeating filament bands by height (right-click an object > Color Pattern...)
- Creality K1 and K2: find printers on your network, CFS support (untested on real hardware, please report)
- Support interface interlock for supports printed in a second filament
- Please check your process presets: since the High Flow work, edits to 11 speed and acceleration settings were not being saved (overhang speeds, internal bridge speed, small perimeter, small support perimeter, initial layer travel, bridge, sparse infill and internal solid infill accelerations). This release fixes it; re-check those values.
- Changed: the bed now heats for the first-layer filament, Klipper printers send MINIMUM_CRUISE_RATIO=0.5, Preview shows coextruded colours by default.
- Fixed: a crash when opening the Filament tab, and several smaller bugs.
<!-- /update-notice -->

A feature release after [2.4.7.6](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.7.6-edge). It includes everything in 2.4.7.6.

## Please read

**Re-check these 11 speed and acceleration values in your process presets (#795).** Since the High Flow work, edits to the settings that take either "mm/s" or "%" were silently lost in every process preset: the field showed the new value, but it was never saved, so the preset (and your project) kept the old one. This is fixed. Your earlier edits were not kept, so please check these values and enter them again if needed:
- the four overhang speeds (10-25%, 25-50%, 50-75%, 75-100%) and the internal bridge speed;
- small perimeter speed, small support perimeter speed and initial layer travel speed;
- the bridge acceleration, sparse infill acceleration and internal solid infill acceleration.

Other behaviour changes:
- **Bed temperature follows the first-layer filament** (#732, Orca #16770). The bed is heated for the filaments that print on the first layer, not for a hotter filament that only starts higher up. For example, a PETG support interface that starts later no longer holds the bed at its temperature from the start: on the Snapmaker U1 the bed goes from 80 to 65 C, and on the Bambu H2D from 70 to 55 C. Your prints may now start with a cooler bed than before.
- **Klipper printers send MINIMUM_CRUISE_RATIO** (#770, Orca #15545). With "accel to decel" on (the default, 50%), the G-code now carries `MINIMUM_CRUISE_RATIO=0.5` as well as `ACCEL_TO_DECEL`. This includes the Snapmaker U1 and Voron profiles. On current Klipper it overrides `minimum_cruise_ratio` in printer.cfg (0.5 is Klipper's own default). The Artillery M1 Pro start G-code sets 0.2, and the slicer's 0.5 now overrides it from the first acceleration change.
- **Preview shows coextruded colours by default** (#784). "Show coextruded colours" is on, so multicolour filaments appear with their colours in Preview. Turn it off in the Preview legend if you prefer one colour per filament.
- **Creality K1 and K2 default to the Creality Print connection** (#777). New printers added from the K1, K1C, K1 SE, K1 CFS-C and K2 Plus profiles use the Creality Print connection. Printers you already saved keep their connection type.
- **Snapmaker U1 is a CoreXY printer** (#761, Orca #16914). Printer settings > Basic information now shows CoreXY instead of "Undefined" for every U1 preset.
- **Web pages no longer go blank when two EdgeSlicer versions run at once** (#786). A test copy now keeps its own web data folder, so Home, the sign-in dialog and the device pages stay visible when you run two different EdgeSlicer versions side by side.

## New

### Multicolour filaments

(#757, #764, #769, #783, #784, #791, #793) Filaments that print in more than one colour at once can now be shown as they look.
- **Split colours.** A filament can be dual or tri-colour (a coextruded silk, for example). Its colours show in the Showcase, sliced and unsliced, and in Preview.
- **Colour make-up editor.** The Filament tab has a "Colour make-up" line with an Edit... button for the colours and their proportions.
- **Gradient filaments.** A gradient filament repeats a colour length followed by a transition length (default 7000 mm and 1000 mm).
- **Glow-in-the-dark filaments.** A glow filament (automatic when the preset name or type contains "Glow", or set in the colour dialog) shows with a "Lights off (glow)" view in Showcase and in Preview's Tool legend.
- **Visual only.** None of this changes the G-code, slicing or what is sent to a printer, and Bambu exports ignore it.

### Color Pattern

(#782, #792) Repeating filament bands by height. Right-click an object and choose **Color Pattern...** (it is also reachable from the colour painting tool). Set the start, band height, gap, number of repeats (or repeat to the top) and the filament sequence, and choose what prints in the gaps. The pattern is one row in the object list that you can edit, reset, detach or remove as one item, with undo. Saved projects keep it. The bands are ordinary height ranges when you slice, so the G-code is the same as hand-made ranges.

### Creality K1 and K2

(#777, includes #616, #618, #619) Network features for the K1 family and the K2 Plus:
- LAN discovery: Find on network lists Creality printers and adds one in a click with the matching preset;
- CFS probe: EdgeSlicer reads the CFS box and its slots, shown as 1A-1D on the swatch map;
- "Use CFS" and "Calibrate before printing" options in the send dialog;
- CFS filament sync;
- sending now reports open and write errors in the send dialog, and uploads go to the right folder for each family.

**Please test and report.** These features were tested against a printer emulator and not on real Creality K-series hardware. If you own a K1, K2 or CFS, please try them and report any problem on [GitHub Issues](https://github.com/aceRage/EdgeSlicer/issues).

The installer adds a Windows firewall rule for mDNS discovery (UDP 5353, private networks) so Find on network can see printers.

### Printing and slicing

- **Support interface interlock** (#758). When the support interface prints in a different filament from the support body, the top interface layers are cut into stripes that alternate the two filaments, and the next layer down is turned 90 degrees, so the interface can't peel off the body. Works with normal and tree supports, top interfaces only. It is off when Support Filament Matching is on.
- **Combine sparse layers for the wipe tower** (#754, Orca #15841). A new option, off by default, prints runs of tool-change-free tower layers as one thicker layer.
- **Wipe tower type setting** (#765, Orca #12781). A new Advanced printer option chooses the Type 1 or Type 2 tower. Bambu printers always use Type 1.
- **Wipe tower auto brim and re-placed tower** (#754, Orca #11831, #16728). With the brim width on auto, the tower now prints its brim. A saved tower position that no longer fits is moved clear of the objects, with a notification.
- **Smoother sparse infill corners** (#766, Orca #16694, #16743). Rounded corners in sparse infill are smoother, and gap fill in monotonic surfaces goes where it adds the least travel.
- **Flow ratio of 0 is refused** (#759, Orca #16719). Slicing now stops with a message instead of writing invalid extrusion.

### Showcase

- **Toolpaths lit like the model** (#755). The sliced look and the layer build-up use the same lighting and finishes as the model view, so a video no longer jumps to a flatter look when it cuts to toolpaths.
- **Silk sheen along the extrusion** (#756). Silk filaments show their sheen along the real direction of the lines.

### Interface and phone hub

- **Place loose objects** (#763). From the phone, objects that hang over the bed edge or sit off every plate can be placed into free space on the plates (or a new plate), and the hub says why a plate can't slice.
- **Drop button** (#753, Orca #16323). The Move panel has a Drop button, and the plate is shown from below while painting.
- **+/- buttons repeat while held** (#753, Orca #16525) in the Emboss, SVG and Cut inputs.
- **3Dconnexion** (#752, Orca #16345, #16670). A "Show 3Dconnexion Settings" item in the View menu, and a faster 3D mouse check at startup on Windows.
- **Ctrl+Q quits** on Windows and Linux (#752, Orca #16722).

## Fixes

- **Crash opening the Filament tab** (#788). Choosing Edit on a filament in the sidebar could close EdgeSlicer.
- **Speed settings not saved** (#795). See "Please read".
- **Blank web pages with two versions running** (#786). See "Please read".
- **Auto-arrange crash** (#762, Snapmaker #1106). Auto-arrange with a part or modifier selected in the object list could crash.
- **Plates kept stale objects after a cut** (#730, Orca #16881). After Cut, or Delete all connectors, later objects could land on the wrong plate.
- **Swatch colours after removing a filament** (#742, Snapmaker #1104). Leftover multi-colour swatches could override the filament colours.
- **Adaptive pressure advance feed rate** (#729, Orca #16857). Adaptive PA could keep the first-layer speed when travel and wall speeds were equal.
- **Temperature tower on multi-tool printers** (#741, Orca #16898). The tower now steps the right hotend on the Snapmaker U1.
- **Wipe tower tags in comma-decimal languages** (#672, Orca #16789). Layer height and line width were written with a comma, and then ignored by the previews and estimates.
- **AltGr in settings fields** (#760, Orca #16918). Typing characters such as `{` or `#` with AltGr on an AZERTY keyboard no longer switches tabs.
- **Mouse pointer after closing a web view** (#743, Orca #16880). On Windows, the pointer no longer stays hidden after closing a web view with Enter.
- **Move and Scale gizmo** (#671, Orca #16730). Fixes uninitialised object and part indices.
- **Chamber temperature warning** (#670, Orca #16764). It is attached to the main window, so EdgeSlicer can exit after it has been shown.
- **Command line results** (#744, Orca #16303). `result.json` is still written when an object name is not valid UTF-8.

## Known issues

- EdgeSlicer can occasionally crash when you open a section of a Showcase panel while the preview video plays.

## Under the hood

- Fixed a use-after-free in the layered-clearance validate test that crashed on macOS (#707).
- The G-code conflict warning names the correct layer (#759, Orca #16588), and seam placement on fully overhanging outer walls is covered by tests (#759, Orca #16334).
- Test copies of EdgeSlicer use their own web data folder (#786).

# EdgeSlicer 2.4.9.8

<!-- update-notice -->
**EdgeSlicer 2.4.9.8** adds Image to object, Paint Split, prime towers for each object, a Basic / Advanced / Bambu settings view and many Bambu H2C / H2D / H3C fixes.
- New: Image to object makes a cookie cutter, a box with a lid or a keyboard-switch clicker from a picture
- New: Paint Split cuts a model along painted regions
- New: Prime tower per object, for plates printed one object after the other
- New: Basic / Advanced / Bambu settings view; Preferences sorted into six tabs
- New: Bambu Lab P3C printer, BirdsEye camera switch, Send without printing, Apply transform
- Fixes: H2C / H2D purge and time estimates now match Bambu Studio; by-object end lift; Fix model keeps paint
- Changed: Snapmaker U1 retraction is now 0.8 mm; PolyMax PETG on H2S / H2C / H3C is PETG
<!-- /update-notice -->

This release follows [2.4.9.7](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.9.7-edge). It bundles the work merged since then (72 pull requests). Please report problems on [GitHub Issues](https://github.com/aceRage/EdgeSlicer/issues).

## New

Image to object
- **Cookie cutter from a picture** (#1132). A PNG or JPG is traced, cleaned up and turned into a cookie cutter with a handle flange, a blade and a sharp edge. The dialog shows the result live.
- **Box with a lid** (#1133). A box in the shape of the picture, with a lid that fits inside the wall. The colours of the picture are inlaid into the lid.
- **Clicker** (#1134). A body in the shape of the picture with a socket for one Cherry MX compatible keyboard switch, and a cap that is pushed onto the stem.
- **Edit again** (#1159). Right-click the object and choose Edit image object. The settings and a small copy of the picture are saved in the project.

Paint Split
- **Cut a model along painted regions** (#1192, #1201). A new gizmo next to Cut. Paint a region with the brush, bucket, smart fill or by picking a colour or segment, and Apply cuts that piece off as a new object or a part, in one undo step.
- **Faster and smoother** (#1221, #1228). The cut follows the skin more smoothly and is much quicker, and Show cut now runs in the background with a Cancel button, so the gizmo stays responsive.

Prime towers and printing by object
- **Prime tower per object** (#1202, #1204, #1207, #1220, #1216, #1222). A new process setting, off by default. On a plate printed one object after the other, each multi-colour copy gets its own small tower beside it, on Bambu printers and on the Snapmaker U1 and Voron style printers. The towers show in the 3D view, can be dragged, and Arrange keeps room for them (up to 4 per plate).

Settings and interface
- **Basic | Advanced | Bambu settings view** (#1197, #1198, #1199, #1200, #1205). A three-way selector replaces the Advance switch. The Bambu view shows only the settings that Bambu Studio shows, under EdgeSlicer's names, and the Add settings menus follow it. New installs start in Basic.
- **Preferences in six tabs** (#1140, #1141). General, 3D View, Projects and Files, Slicing and Presets, Printers and Network, Apps and Advanced. Collapsible sections, a search box and translated titles.
- **Apply transform** (#1156). Right-click an object or part, or use the button in the Move, Rotate and Scale panels, to bake the current rotation, scale or position into the mesh so it becomes the new 0 degrees, 100 percent baseline.
- **Discord Rich Presence** (#1162). Off by default, in Preferences > General > Privacy. Shows the open project and the print progress on your Discord profile, through the local Discord app only.
- **Device page: tool temperatures** (#1151, #1152, #1153). Printers with three or more tools get a compact temperature list, and the H3C rack nozzle temperatures are shown (read only).

Bambu Lab printers
- **Bambu Lab P3C** (#1215). Printer, filament and process presets from Bambu Studio 2.9.2.
- **BirdsEye camera** (#1208, #1209). A button on the Device page switches between the live-view cameras, and the camera settings have a recording switch for each camera.
- **Send and Send all** (#1195). Upload the sliced file to the printer without starting a print, from the print button's dropdown.
- **Bambu Studio 2.9 settings** (#1206, #1210, #1213, #1217, #1223, #1227). Height slowdown, initial layer infill line width, Auto infill retraction, filament metal stickiness, per-filament overhang speed overrides, the cooling filter accessory, adaptive volumetric speed, and the auxiliary fan and pre-start fan settings. Presets that carry the keys resolve to Bambu's values.
- **Bambu X2D** (#1219). The right extruder is a Bowden extruder, and now retracts like one (2 mm at 20 mm/s).
- **Polymaker G-Flex PETG** (#1161). New presets, including H2C, H2D and H3C.

Support fins (off by default, Advanced view)
- **Support fins** (#1218). Breakaway fin walls beside a part that is printed tilted onto an edge, with one-layer tines that fuse into the part. The technique is Slant3D's "designed-in supports", as described by Support Fins (printfins.com, MIT). The planner is EdgeSlicer's own.
<!-- PENDING #1225 -->
- **Bake fins** (#1225, not merged yet). Right-click an object to turn its live fins into real geometry that prints in any slicer. Fins now take the space from supports.
<!-- PENDING fins PR 3 (no number yet) -->
- **Stabilizer ribs** (fins PR 3, no PR yet). Sway-brace ribs added to the stabilizers.

## Fixes

Bambu H2C / H2D / X2D / H3C
- **Purge now matches Bambu Studio** (#1160, #1169, #1163, #1167). The purge is worked out from what the target nozzle last held, the flush matrix is read the right way (one shared matrix, or one per nozzle), a manual filament map decides the extruder, and pinned rack filaments spread over free nozzles. Existing H2C and H2D projects can slice differently: automatic filament maps and purge amounts change, and some plates use more filament.
- **Time and filament estimates** (#1165). Estimates on H2C, H2D, H3C, A2L, P2S and H2S now include the firmware purge time and grams.
- **Hotend rates** (#1171, #1174). The change template and the prime tower ramming use each extruder's own hotend heating and cooling rate on the H2C.
- **H3C printed by object** (#1196). Hotends are now planned for multi-colour plates printed one object after the other; a plate could stop at 97 percent.
- **A2L printed by object** (#1172). The nozzle lifts above the tallest object before the end G-code, and a warning shows when a tall object is within the gantry's reach.
<!-- PENDING #1230 -->
- **H3C fan speeds** (#1230, not merged yet). Fan raise from Bambu Studio 2.9.2 on the H3C filament presets, and a stray setting removed that logged "incorrect keys" on every H3C process preset.
- **Cooling parity** (#1227). Auxiliary fan in the early layers and the pre-start fan, and the left auxiliary fan on the H3C.

Slicing
- **Cooling timing** (#1170). Layer cooling now times a layer by acceleration, as the Preview does, so cooling follows the more accurate time. Fan values can differ slightly on existing profiles.
- **Resonance avoidance** (#1166). Outer walls stay out of the resonance range through the cooling slowdown.
- **Arachne** (#1143). Short stubs in the wall skeleton are now pruned, which changes thin wall output on every printer.
- **Bridges and supports** (#1194, #1149). Bridges that are a region of their own are anchored on the regions next to them, and normal support expansion stops at thin walls.
- **Top surfaces** (#1164). Clearance and the one-wall-on-top fill follow the printed top, including a raft.
- **Upstream fixes** (#1139, #1144, #1146, #1147, #1150, #1155, #1157, #1193). Small fixes from OrcaSlicer and Snapmaker Orca: G-code, slicing, Measure after uneven scaling, the Cut gizmo right click and crash fixes.

Models and projects
- **Fix model keeps paint** (#1203). Fix model, remesh, simplify and subdivide no longer erase colour, support, seam and fuzzy-skin painting, and no longer clear the parts that were not repaired.
- **Upload names** (#1191). Send dialogs remove forbidden characters from the file name instead of asking.
- **Command line** (#1211). A by-object Bambu project that did not change is no longer re-arranged by `--slice`.

Profiles
- **Snapmaker U1 retraction is 0.8 mm** (#1214). It was 1.5 mm. The Bambu library Direct Drive Standard filament flow now follows the X1C.
- **PolyMax PETG** (#1161). On H2S, H2C and H3C it is now PETG, not PC, so its temperatures change for existing users of that preset.

Crashes
- **Crash at exit and in the temperature tower** (#1173). Fixed an abort when closing the app, and a crash when starting the temperature tower calibration after switching projects.

## Under the hood

- Settings view tables and the Bambu key list updated to Bambu Studio 2.9.1 (#1197, #1206).
- Multi-tool temperature model for the Device page (#1151).
- Mac: Sentry is built for macOS 11.0 so the app starts on macOS 11 (#972).
- Tests: Mac float margin in the ContourZ test (#1137), a flaky test with non-ASCII file names (#1212).
- Wipe tower refactor, no G-code change (#1204).
- Build fix for the Windows `near` macro (#1229).

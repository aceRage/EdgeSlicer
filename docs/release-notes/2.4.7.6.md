# EdgeSlicer 2.4.7.6

<!-- update-notice -->
Fixes in 2.4.7.6:
- Send to Bambu Connect: files sliced with your own process presets now import instead of leaving Bambu Connect on a white screen
- Sliced files and sends no longer carry your printer's serial, its name or your print history
- Snapmaker U1: filament Sync now finds your own presets and creates one for third-party RFID spools, instead of falling back to Generic PLA
- Fixed instant crashes when binding a Snapmaker U1 or a Bambu printer by IP address
<!-- /update-notice -->

A small fix release after [2.4.7.5](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.7.5-edge). It includes everything in 2.4.7.5.

## Fixes

- **Send to Bambu Connect** (#746). A file sliced with a user or custom process preset turned Bambu Connect's window white on import, and it never recovered. The project settings in the sliced file now always list the printer the file was sliced for, which Bambu Connect needs, so the file imports and passes Bambu Connect's printer check. Opening that sliced file again in EdgeSlicer does not lock your process preset to that printer.
- **Privacy in sliced files** (#745). Sliced files, printer sends, Send to Bambu Connect, phone sends and the command line no longer include your printer's serial number, its name or the plate's print history. Saved projects still keep them for your own use.
- **Snapmaker U1 filament Sync** (#740). The U1 reports the vendor, type and sub-type of each loaded spool (from its RFID tag). Before, EdgeSlicer only matched exact system preset names, so a preset you had saved yourself never matched and Sync picked Generic PLA. Now:
  - Sync and the filament dropdown use the same matching: exact name (system first, then your presets), then the same vendor and type with the closest colour, then Generic;
  - a third-party spool with no preset of its own gets a new user preset such as "iBoss PLA Silk @U1 0.4 nozzle", based on the Generic U1 preset (pressure advance stays off). Later syncs reuse it rather than making duplicates;
  - every loaded toolhead now shows under Machine Filament in the dropdown.

  Snapmaker U1 owners with third-party tags: please report on GitHub Issues if Sync still picks the wrong preset.
- **Crash binding a Snapmaker U1 by IP** (#747). If the printer refused the connection (a closed or firewalled port, or another connection mode), EdgeSlicer closed instantly. It now shows a normal connection failure.
- **Crashes binding a Bambu printer by IP** (#748). An error during the bind, a missing network plug-in, or pressing Cancel while the bind was still running could close EdgeSlicer. These now show an error or cancel cleanly. Some printer list and send dialog background tasks got the same protection. This may fix instant crashes reported on macOS and Linux; please tell us if you still see one.
- **Discord** (#749). Issue templates point at the new EdgeSlicer Discord server.

# EdgeSlicer 2.4.7.5

<!-- update-notice -->
New in 2.4.7.5:
- Elegoo Centauri Carbon 2: much faster print profiles, plus new LAN sending with CANVAS, status and a device page (tested on an emulator, not a real printer)
- Push-fit Pin connector and multiple dovetails for cuts, and paint now survives a cut
- Spread paint tool, DXF export of traced and SVG outlines, better image tracing
- New infill patterns, ironing overrides, a skirt and brim overhaul and bridge controls
- Prime tower: rotation, ribs inside the placed outline, and fixes for non-Bambu multi-material printers
- Faster startup and faster slicing of detailed models
- Changed: an explicit ironing angle is now an offset, and Cyclic tool ordering really keeps a fixed order (more tool changes)
<!-- /update-notice -->

The next release after [2.4.7.0](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.7.0-edge). It includes everything in 2.4.7.0.

## Please read: things that behave differently

- **Ironing angle** (#716). An explicit ironing angle is now an offset from the top/solid infill direction, not an absolute angle. For example, 90 now irons at 135 when the infill direction is 45 degrees. Prints with the default setting are unchanged.
- **Cyclic tool ordering** (#712). It now really keeps one fixed filament order on every layer. That means more tool changes when you choose it. It also fixes the H2C export error "Wipe tower generation failed, possibly due to empty first layer".
- **Prime tower on non-Bambu multi-material printers** (Snapmaker U1, Voron, MMU, toolchangers, Elegoo Centauri Carbon with CANVAS) (#720, #721, #722):
  - rib towers now sit inside their placed outline;
  - travel into the tower goes around it, through the gap in the wall;
  - purge blocks for tools that do not ram now fill whole rows.

  Other prime tower changes: towers stay on round and other non-rectangular beds (#713), there is an optional wait for temperature on the tower (#714), and on Klipper the tower's flush and dwell now really wait (#708).
- **Elegoo Centauri Carbon 2** (#734, #736, #737, #738). Print profiles are fixed: they were tuned like an old Elegoo Neptune, so prints are now much faster. The default bed is Textured PEI, and "PLA Translucent2" is renamed "PLA Translucent". See the Elegoo section below for the new sending features, and for what has and has not been tested.
- **Command line** (#726). Auto-arrange no longer rotates parts unless you pass `--allow-rotations`.
- **Slicing defaults** (#718, #719):
  - "Only one wall on top/first layer" does nothing when the top/bottom shells are 0;
  - Adaptive Cubic and Support Cubic infill are built separately for each body;
  - top and bottom surfaces with partial density and a plane-path pattern are centred on each surface.
- **Skirt and brim** (#704). Multi-object and multi-instance plates, per-object skirts, draft shields and by-object prints can get different skirt and brim G-code. One-object prints with the default brim are unchanged.
- **Curled perimeter slowdown** (#678) is now off by default, as in OrcaSlicer.

## New

### Elegoo Centauri Carbon 2

**Please test and report.** The Centauri Carbon 2 sending, CANVAS and status features below were tested against a printer emulator, not a real Centauri Carbon 2. If you own one, please try them and report any problem on [GitHub Issues](https://github.com/aceRage/EdgeSlicer/issues). Issues are newly enabled, with templates for bug reports, feature requests and printer or profile requests (#724).

- **Print profiles** (#734). 17 of the 21 Centauri Carbon 2 process presets were tuned for an old Neptune, with low acceleration and slow travel and top-surface speeds. They now use the Centauri Carbon 2's own values, so prints are much faster. Other changes: the default bed is Textured PEI (#736) and "PLA Translucent2" is renamed "PLA Translucent" (#736).
- **LAN sending** (#734). Upload, start print and CANVAS tray mapping over the printer's own protocol.
- **CANVAS auto-refill and status** (#737). Auto-refill between trays of the same material, and the Centauri Carbon 2 appears in the hub, the phone app and the Printers tab with live status.
- **Device page** (#738). A device page that uses one shared template for printers, with sections in the order of the Bambu Device tab.
- **Centauri Carbon 1 Storage tab** (#681). List, delete and start files stored on the printer.

### Cutting and painting

- **Push-fit Pin connector** (#693, #698, #699). A new connector type for cuts: a pin that prints separately, lying flat, and is pushed into holes in both halves. Presets S, M, L and Auto, or set every size, clearance and end shape yourself. Cuts also remember where each part sits in the assembled model.
- **Multiple dovetails** (#697). Dovetail cuts can have several dovetails side by side, with count, gap and spacing (up to 20).
- **Painting survives a cut** (#687). Support, seam, colour and fuzzy-skin painting are kept on both halves.
- **Edit cut keeps the painting** (#709).
- **Spread paint tool** (#694, #695). In the colour painting gizmo, press and hold on the model and the colour grows over the surface from that point, measured over the surface in mm. A five-step slider sets the speed.

### Images, text and shapes

- **DXF export** (#717). Export traced image outlines, SVG parts and text parts as DXF for CAD and laser tools. The image trace dialog has an Export DXF button, with one layer per colour. Right-click an SVG or text part for "Export outline as DXF".
- **Image trace colours** (#733). Small, distinct colours in line art, such as bright shapes on a dark background, are no longer merged into the larger colours. A new "Match filaments" menu and a preview colour toggle were added.
- **Text and fonts** (#675). Cyrillic, Greek, Vietnamese and other non-Latin text no longer shows as question marks or garbage, and several emboss and font-picker fixes came with it.
- **STEP import** (#686). Accented part names import correctly, reload from disk works for STEP files after reopening a project, and the progress percentage is right.

### Showcase

- **HDR rendering with a Filmic tone option** (#735). Objects are drawn in high dynamic range and go through one tone-mapping pass, so highlights and dark areas keep detail.
- **Floor image rotation** (#703). A floor picture now stands upright, and it can be rotated in 90 degree steps and flipped.

### Slicing

- **New infill patterns and options:**
  - **Spiral Inset** (#685) infill for solid surfaces and support interfaces;
  - **Optimized Gyroid** (#696), an experimental option that biases the gyroid against Z buckling;
  - **Sparse infill corner smoothing** (#705) for the Hilbert Curve and more patterns;
  - **3D Honeycomb** (#706) rewritten, with optional filled octahedron tops;
  - **Adaptive TPMS** and adaptive infill density (#710).
- **Ironing** (#716). Per-filament ironing overrides (flow, spacing, inset and speed), plus a relative or fixed ironing angle.
- **Top and bottom surfaces** (#718, #719). Set the top and bottom layer directions yourself, expand the top surface, and choose how plane-path patterns are centred. A "Separated infills" option and a choice of top/bottom fill order were added.
- **Skirt and brim overhaul** (#704). Per-instance skirts and brims, combined brims, mouse ears and brim flow.
- **Bridge controls** (#684). Bridge line width, bridge density up to 125%, relative bridge direction, and bridge and ironing angles that follow the model's rotation.
- **Prime tower rotation** (#700). A rotation field in the Process tab, and the Rotate tool (R) works on the tower in the 3D view.
- **Wipe tower settings** (#690, #714). Fixes for first-layer gaps when the spacing is not 100%, and an optional wait for the toolchange temperature on the tower (off by default, on in the Custom MyToolChanger profiles).
- **Custom G-code** (#678, #727).
  - A file header G-code (`file_start_gcode`) is written first in the file.
  - New placeholders: `{print_time_sec}`, `{print_time_total_sec}`, `{used_filament_length}`, and print statistics such as `total_weight`, `print_time`, `total_cost` that now work in custom G-code.
  - A "skip G-code config block" option, an extrusion role change G-code in Process and Filament, and a retract-after-wipe option.
  - A tolerance setting for the outlines used by Klipper's exclude-object (#727).
- **More small print options** (#678). Arachne maximum resolution and deviation, Lightning infill angles, small perimeter speed for supports, and a limit on polyhole edges.
- **Post-processing scripts on .gcode.3mf** (#650). They now run when a non-Bambu printer's G-code is packed as .gcode.3mf, for example when sending a sliced plate to a Moonraker printer.

### Printers and apps

- **Klipper MMU slots** (#612). The send dialog shows the gates of a Happy Hare MMU or the lanes of an AFC, with colour and material. This is display only: no gate or lane mapping is sent when the print starts.
- **Hub: cloud Bambu progress and thumbnails** (#715). Cloud-bound Bambu printers in the phone app and the hub now report their real state, progress and age instead of 0% with no state.
- **Hub: slicing for the phone app** (#673, #674). The hub can now report a sliced plate's filament use and cost, cancel a slice, preview a send before anything is sent, and take an explicit Bambu tray mapping, for the companion app's Slice tab.
- **Profile updates** (#725). Follow-ups for Creality (start G-code now waits for the nozzle temperature), Anycubic, RatRig, Anker, School House Spools, UltiMaker, Sovol and Blocks.

### Interface and workflow

- **Warnings and dialogs** (#677). Every print validation warning is shown, collision warnings name the instance and "Jump to" selects it, the bed type and filament check works for all printers, Enter confirms the Clone dialog, error excerpts point at the blamed character, and notice dialogs say OK.
- **Plates and instances** (#679). Moving an instance to another plate registers it on that plate, the By-object arrange settings are saved, Support painting gets Vertical and Horizontal lock checkboxes, and the move, rotate and scale panels are laid out more compactly.
- **Reload from disk for several objects** (#644). Available when several objects or parts are selected.
- **Help > About** (#692) shows the correct fork credits and copyright, and links to the EdgeSlicer GitHub page.

### Faster

- **Startup** (#680, #688, #689, #701, #702). The filament library is reinstalled only when it changed, the Bambu preset mirror skips its work when nothing changed, the Showcase view and Compare presets are set up on first use, the font atlas is built once, and user presets are read in parallel. The startup splash also shows its phases and a progress bar (#683).
- **Slicing detailed models** (#668) such as HueForge-style reliefs, and **objects made of many parts** (#669), which no longer spend most of their slice time deciding which parts touch for the brim.

## Fixes

- **Cyclic tool ordering and the H2C wipe tower error** (#712). See the top of these notes.
- **Reload from disk** (#676) picked the wrong object when a 3MF had several objects. It now finds the right one.
- **Single-filament sync** (#647). After syncing a single filament of a different type (for example PLA to PETG), the pre-print page kept the old filament and the print could not be started.
- **Filament and extruder counts** (#649). A project with 2 nozzles and 4 filaments could lose or misassign custom high-flow values when reopened.
- **Config values** (#648). A setting given an unreadable value no longer overwrites the existing value.
- **Slicing thread race** (#645). A leftover step could read the print config while slicing was rewriting it.
- **Sidebar sections** (#665) no longer fold by themselves after a selection dialog closes.
- **Device page** (#723) no longer shows a blank page after startup in some cases.
- **Prime tower cone base** (#667) is only reserved when the wall type is Cone.
- **Undefined behaviour in EdgeGrid** (#646) removed. Distance values are unchanged.

## Under the hood

- **Printer emulator** (#654, #659, #662, #682). A developer tool, not part of the installer: fake QIDI, Elegoo Centauri Carbon 1 and Snapmaker U1 printers that EdgeSlicer is pointed at by IP, with a command log and send gates. It is how the Centauri Carbon 2 features were tested.
- **Test copies and the phone hub** (#691). `--no-hub`, `--take-hub` and a marker file keep test copies from taking over the phone hub of the main install.
- **Build** (#711, #728). The VM build no longer exceeds the 4 GB library limit, and two checks that failed on every pull request are fixed.
- **Issue templates** (#724). Bug reports, feature requests and printer or profile requests, in place of the inherited templates.

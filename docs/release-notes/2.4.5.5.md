# EdgeSlicer 2.4.5.5

<!-- update-notice -->
New in 2.4.5.5:
- Bambu live view works on macOS again, with a new built-in camera view
- Connectivity and stability fixes for Bambu Lab and Snapmaker printers
- Vendors: Download & Open, and pasting a connector works on macOS
<!-- /update-notice -->

Everything in [2.4.5.4](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.5.4-edge) is included.

## New

- **New Bambu LiveView** (#448). Bambu printer cameras play through EdgeSlicer's own viewer (the same stream the phone app uses), on Windows and macOS. It is on by default; turn it off in Preferences to use Bambu's own camera player instead, which is now included as well (#443).
- **Vendors: Download & Open** (#446). Save a model from a connected vendor and open it straight away.
- **Live Activities from the PC** (#355, #359). With the next phone app update, the Lock Screen and Dynamic Island can be kept current by EdgeSlicer itself (opt-in in the app), and print alerts refresh the activity in the background.
- **Faster, steadier fan control** (#451, OrcaSlicer batch 2B). The overhang fan no longer leaks into the next filament after a tool change, and fan speeds are kept per filament.

## Fixes

- macOS: Bambu live view, no "Log in printer" prompt for LAN-only printers, Bambu sign-in is remembered, no crash on quit, and pasting a vendor connector works (#443, #444, #445, #452).
- Printers answer the first request after start-up, and the Snapmaker Device page loads once without start-up timeouts (#442, #449).
- Snapmaker U1: thumbnails, time and filament show on the printer again (#431), and time left matches the printer's own estimate (#441).
- A crash after using Assemble is fixed (#440).
- The phone app's camera no longer opens a second connection to the printer (#450).
- Connect via IP no longer adds a printer without a serial number (#447).

## Under the hood

- Remaining old product names now say EdgeSlicer (#431). G-code is stamped "OrcaSlicer <version> (EdgeSlicer)" so printers read its metadata.
- Smaller OrcaSlicer fixes: AMF/3MF hardening, mesh boolean differences, vase mode per object, quieter Bambu Studio project imports (#398, #401, #402, #404).

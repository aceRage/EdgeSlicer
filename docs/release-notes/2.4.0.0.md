# EdgeSlicer 2.4.0.0

<!-- update-notice -->
New in 2.4.0.0: High-Flow hot end support with refreshed Snapmaker U1 profiles, Export Bambu 3MF, dockable/collapsible tool panels with opacity control, custom toolchange order with proper filament sequence fallbacks, more improvements to the draw-cut type.
EdgeSlicer now tells you when a new version is out and can send crash reports if you turn that on (off by default).

Fixes:
- Bambu Studio presets and projects from dual-nozzle printers (H2D/H2C) now import correctly, and a preset that can't be read is set aside instead of deleted.
- Bambu Studio setting names (prime tower, wipe speed, clearance radius and more) now carry over when you open Bambu projects and presets.
- The Cut tool and the text/SVG Modifier option now appear in Simple mode.
- Extruder-change retraction on the H2D now matches Bambu Studio.
- Bambu printer error dialogs show the right message, and their Resume/Stop buttons work.
- Edit cut and Copy cut no longer crash, and arranged piles stay on the bed.
- G-code import and organic/raft wipe tower crashes are fixed.
- FlashForge uploads keep their file names intact on the touchscreen.
- Modifiers that change nothing or overlap no part now warn at slice time.
- The selection highlight has a softer glow with configurable glow value, and a thin outline option in Preferences.
- Web surface hardening, removed several vendor-specific entry points and collectors, HTTPS/SSL fixes.
<!-- /update-notice -->

Everything in [2.3.8.5](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.3.8.5-edge) is included.

## What's new

### Printers and profiles

**High-Flow hot ends.** The Snapmaker U1 High-Flow hot end parameters are in. Settings that differ between the standard and High-Flow nozzle are kept per variant, with a *Both* mode and a one-click copy from Standard to High flow. The U1 presets track Snapmaker's v2.4.0 profiles.

**Bambu Lab H2D.** The per-filament *long retraction on extruder change* options are ported, so switching nozzles retracts the way Bambu Studio does. There are 15 new Polymaker Panchroma filament presets for the H2D.

**Printer error actions.** Bambu's error dialogs now show the buttons the printer offers (Resume, Stop, Ignore, Retry and the rest) and send the matching command. When a command is refused, the reason is shown. The same actions are available from the hub page.

### Bambu Studio compatibility

**Export Bambu 3MF** (File › Export) writes a project that Bambu Studio opens with its settings intact. Settings Bambu Studio doesn't have are left out, and a notice says how many. The rest are converted to Bambu's names and formats. Normal saves are now labelled as EdgeSlicer projects. Bambu Studio opens those as geometry only; OrcaSlicer and Snapmaker Orca still load their settings.

**Importing from Bambu Studio.** Presets and projects from dual-nozzle printers, which fill unused per-nozzle slots with `nil`, now load. That applies to per-object settings too. Bambu's names for renamed settings are mapped onto ours, and a preset EdgeSlicer can't read is moved to an `unloadable` folder instead of being deleted. *Preferences › Re-pull all* recovers presets an earlier sync removed.

### Tools and interface

- **Tool panels** can be docked, collapsed, and made more or less opaque (*Preferences › General › Gizmo panel opacity*).
- **Toolchange order** can follow a cyclic or custom filament sequence, and falls back to the plate's customised sequence when that is set.
- **Right-click › Export part as STL…** saves a single part, modifier or negative volume.
- **The Move tool** can hide the other plates while you move objects.
- **Overlapping parts** can carve each other regardless of their order in the object list (Bambu Studio's option; off by default).
- **Full Spectrum Auto Match** lets you pick the colours it matches from your colour library.
- **Selection highlight:** a tighter glow that stays off neighbouring parts, a glow-strength setting, and a thin outline style.
- **Draw cut** handles open strokes, edges and connectors more reliably.
- **New command-line options:** `--inspect-paint` dumps painted regions as JSON, and `--export-bambu-3mf` writes a Bambu-compatible project.

### Updates, privacy and security

- **New-version notice:** EdgeSlicer checks this repository's latest release at startup and shows a short summary. It can be turned off in *Preferences › General*.
- **Crash reports (opt-in):** *Preferences › General › Privacy › Send crash reports* is off by default. When it's on, a crash sends its stack trace, the app version, the OS and a few recent log lines. Printer addresses, access codes, serial numbers, tokens and your username are removed before sending. See [docs/privacy.md](https://github.com/aceRage/EdgeSlicer/blob/main/docs/privacy.md).
- **Removed:** the Customer Experience Improvement Program checkbox, Snapmaker's remote updates of profiles and built-in web pages, and the PostHog analytics loader.
- **Certificates:** internet connections now check certificates. Printers on your local network connect as before; a printer with a CA file set is checked against that file.
- **Local page server:** it now answers only EdgeSlicer's own windows and serves only the files it hands out.

## Behaviour changes to know about

- **Print-by-object clearance.** Eleven printer profiles now use the vendor's own, larger clearance radius for print-by-object: Bambu A1, A1 mini, A2L and X2D; Qidi Q2, Q2C, X-Plus 5 and X-Max 4; Elegoo CC2; Geeetech. Objects are spaced a little further apart.
- **Anycubic Kobra S1 Max.** 15 process presets now use a rib wipe tower wall, as their profiles specify.
- **Simple mode.** The Cut tool and the text/SVG Modifier part type are available in Simple mode.

## Fixes

- **Zero speeds.** A speed that works out to zero now stops the slice with a warning naming the setting, the object and the layer, instead of writing a move with no speed.
- **Arrange.** Custom alignment keeps piles on the bed.
- **Cut crashes.** *Edit cut…*, *Copy cut to…* and *Mirror* no longer crash or hit an invisible stop.
- **Crashes fixed:**
  - importing G-code with the filament view;
  - organic supports and raft wipe towers;
  - a Bambu AMS tray whose filament preset was removed.
- **FlashForge.** Upload names keep spaces, parentheses and non-ASCII characters.
- **Modifiers.** A modifier that changes no settings or overlaps no part now warns at slice time. A modifier listed above its part attaches to it.
- **Wipe.** Wipe-on-loops ends at the right nozzle position, and a new *wipe inward* option is added.
- **Profiles.** Snapmaker filament profiles have their filament IDs, the U1 generic filaments keep their `@U1 0.4 nozzle` names, and asset filenames are fixed for case-sensitive systems.

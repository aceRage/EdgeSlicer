# EdgeSlicer 2.4.9.7

<!-- update-notice -->
**EdgeSlicer 2.4.9.7** fixes starting a print on the Elegoo Centauri Carbon 2.
- Fixed: Centauri Carbon 2 "the printer has too many connections open" after the file was sent
- Changed: the print start now uses the connection EdgeSlicer already has to the printer
<!-- /update-notice -->

This is a small fix release for the **Elegoo Centauri Carbon 2**. It follows [2.4.9.6](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.9.6-edge). Please report problems on [GitHub Issues](https://github.com/aceRage/EdgeSlicer/issues).

## Fixes

Printers and sending
- **Elegoo Centauri Carbon 2: print did not start** (#1130). After 2.4.9.6 the file reached the printer, but the print could fail to start with "The file has been transferred, but the print did not start: the printer has too many connections open". EdgeSlicer opened a new connection to the printer for each task, and the printer only allows a few.
  - The print start is now sent over the connection EdgeSlicer already keeps to the printer, so it needs no extra one.
  - Where EdgeSlicer has to open its own connection, it uses one fixed name for each task, so a repeat does not take another place on the printer.
  - A "too many connections" answer is tried again twice, after 2 and 4 seconds, before the error is shown.
  - A start request that was sent and got no answer is never sent a second time, so a print cannot start twice.
  - The error message now says that the file is already on the printer and can be started from the printer's screen.
  - A user with a Centauri Carbon 2 confirmed that this build sends and starts a print.

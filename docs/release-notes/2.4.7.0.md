# EdgeSlicer 2.4.7.0

<!-- update-notice -->
New in 2.4.7.0:
- Showcase: filament callouts, camera paths and videos with a layer-by-layer build-up
- Camera wall for the TV app: all your printer cameras in one fast-loading stream
- QIDI Box and Elegoo CANVAS: safer slot mapping, empty and mismatched slots are refused
- Better walls, bridges and tree supports from the latest OrcaSlicer fixes
- Snapmaker U1: updated start G-code and purifier control
- Fixed user presets disappearing after "Detach from parent"
<!-- /update-notice -->

The next feature release after [2.4.6.3](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.6.3-edge). It includes everything in 2.4.6.3 and the QIDI Box fixes from the [2.4.6.4 release candidate](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.6.4-edge).

## New

### Showcase

- **Filament callouts** (#656). Label each filament on your renders with its brand, product, material family, colour name, hex code and swatch, price or weight. Pick which fields show, the separator between them, straight or elbow leader lines, and whether each colour is called out once per plate. Labels can be dragged, pinned and edited.
- **Videos** (#657). Turn a scene into an MP4, WebM, GIF, WebP or PNG sequence: orbit, turntable, static and zoom-out camera paths, or your own keyframes. Callouts can follow the model or stay put, and can appear only once their colour starts printing.
- **Layer build-up and path files** (#658). Show the print growing layer by layer from the real toolpaths, with infill and supports optional. Camera moves and timed changes to lights, backdrop and callouts can be scripted in a path file, imported in the Showcase tab or rendered from the command line with `--showcase-render`. Showcase panel sections can be folded.

### Printers and apps

- **Camera wall for the TV app** (#655). The hub combines your printer cameras into one stream per page, so a TV with few video decoders can show them all. Cameras appear within a second or two, a camera that is offline shows an "Offline" card without holding up the others, and the stream stops by itself when nobody is watching.
- **Vendors: fixed field values** (#664). In a vendor connector's field mapping, a value starting with `=` is used as-is for every item, for example Designer `=N3D`. Tags take a list (`=a, b`).
- **Overhang depth and extra bridge expansion** (#603, #604). Two new options, both off by default: slow down the inner wall behind an overhang, and grow bridging infill into the solid infill around it (Quality > Bridging, Advanced mode).

## Fixes

### Sending to printers

- **QIDI Box slots** (#661). Which slots are loaded is read from the Box's slot sensors, as QIDIStudio does, so empty slots no longer show as PLA. Box data that contradicts itself means upload only, and a filament mapped to an empty slot is never started.
- **Elegoo CANVAS and Snapmaker U1 sends from the phone, hub and Stream tab** (#660). Trays are mapped like the desktop send dialog, a filament going to a tray of another material is refused, and a busy printer is refused before anything is uploaded. A U1 that has just finished a print is no longer seen as busy.
- **"No available printers"** (#628) is shown instead of an empty printer list.

### Slicing

- **Arachne walls** (#634). Odd wall lines follow the same order as even ones, outer walls sharing a centre line print as one island, and a new Outer-only brim option.
- **Internal bridges** (#636) anchor better over sloping infill. This changes G-code slightly for most prints.
- **Tree supports** (#633). Fixed missing support paths and misplaced extra walls.
- **Filament shrinkage** (#560) is now applied on the first slice, not only from the second.
- **Z contouring** (#557) works on objects with more than one copy.
- **Shared heaters** (#551). A heater shared by several filaments stays on until all of them have finished.
- **G-code header** (#559). The first-layer nozzle and bed temperatures in the header are those of the first filament actually printed.
- **Mixed colours** (#552). Manual colour matching allows the full 0-100% range again, with a warning at the extremes.

### Snapmaker U1

- **Start G-code and purifier** (#635). Updated U1 start sequence: purifier alarm temperature, first-tool pre-extrude and fan control around probing.
- **Default filament** (#630). With every filament deselected, the U1 falls back to Generic PLA @U1.
- **Nozzle hardness warning** (#629) when a filament needs a hardened nozzle.

### Interface and stability

- **User presets** (#653). Presets built on a detached user preset no longer vanish on restart, and "Detach from parent" moves the preset into the right folder.
- **Crash selecting a user printer** whose parent printer isn't loaded (#631).
- **Crash closing the phone and device dialogs** (#558).
- **Sidebar colour swatches** after opening a geometry-only 3MF (#627).
- **Slice progress** is kept after a printer connects (#626).
- **Keyboard shortcuts** no longer fire while typing in 3D-view text fields (#553).
- **Setup Wizard** pages load more reliably (#556).
- **Linux**: graphics workarounds for WebKitGTK and NVIDIA now depend on the installed version (#562).

## Under the hood

- Command-line Showcase renders start no hub or camera helpers (#663).

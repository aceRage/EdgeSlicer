# EdgeSlicer 2.4.9.4

<!-- update-notice -->
**EdgeSlicer 2.4.9.4** is a small fix release. It is otherwise identical to 2.4.9.3.
- Fixed: a print whose first filament is not filament 1 no longer lists filament 1 as used (Bambu Connect and the send dialog asked for a filament the plate does not use)
- Fixed: single-filament prints no longer show "Filament change times: 1"
- Re-slice projects that were sliced with 2.4.9.2 or 2.4.9.3
<!-- /update-notice -->

This is a hotfix for one bug. It follows [2.4.9.3](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.9.3-edge) and is otherwise identical to it. Please report problems on [GitHub Issues](https://github.com/aceRage/EdgeSlicer/issues).

## Please read

Re-slice affected projects. A file sliced with 2.4.9.2 or 2.4.9.3 on a Bambu printer, where the first filament used was not filament 1, still lists filament 1 and keeps the old tool change count until it is sliced again.

## Fixes

- **A print whose first filament is not filament 1 no longer lists filament 1 as used** (#1098). In 2.4.9.2 and 2.4.9.3 the sliced file recorded about 0.01 g on filament 1 for such prints on Bambu printers, so Bambu Connect and the send dialog asked for a filament the plate does not use. Single-filament prints no longer show "Filament change times: 1", and the time estimate no longer adds a tool change for the first filament load.

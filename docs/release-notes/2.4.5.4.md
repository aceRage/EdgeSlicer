# EdgeSlicer 2.4.5.4

<!-- update-notice -->
New in 2.4.5.4:
- Printers answer the first time you select them (no more failed first request)
- Snapmaker U1: model detected straight away, and no "Unsaved Changes" popup when connecting
- macOS: signing out of Snapmaker now fully signs you out
<!-- /update-notice -->

Everything in [2.4.5.3](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.5.3-edge) is included.

## Fixes

- **First request after selecting a printer** (#436). Selecting a printer on the Device tab sent requests before the connection to it was up, so the first ones failed (errors in the log, and calibration data could be missing until the next refresh). Requests made while a printer is connecting now wait and go out the moment it is connected, in order. Each connect logs how long the connection and the first status took.
- **Snapmaker U1 model detection on the Device page** (#436). The first question to the printer could be answered before EdgeSlicer was listening for the reply, which caused a 5 second wait and sometimes the "model detected as" question. EdgeSlicer now waits until it is listening, and asks once more if there is still no answer.
- **No "Configuration package changed: Unsaved Changes" popup on U1 connect** (#436). Connecting to a U1 reloaded every preset even when nothing had changed, which asked about your unsaved settings. Nothing is reloaded now when the U1 is already set up, and when a connect does add something (for example a new nozzle size) your modified values are kept without asking.
- **Bambu cloud printers get one status request on connect** (network plug-in). Cloud printers were asked for a full status two or three times when the cloud connection came up.
- **macOS: Snapmaker sign-out** (#435). Signing out now clears Snapmaker's saved sign-in on macOS too (as on Windows since 2.4.5.3), so the next sign-in shows the form instead of flashing. A harmless page-load message during Google sign-in is no longer logged as fatal.

## Known limitations and not tested

- Checked by hand on Windows and macOS: Bambu LAN and cloud printer selection, U1 Device-page connects, Snapmaker sign-in and sign-out.
- Linux: Snapmaker sign-out still only clears the saved sign-in while a sign-in window is open.
